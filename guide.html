使用指南

按目标组织的操作手册：找到你想做的事，照着步骤做即可。

入门 使用指南 CLI 参考 数据与安全 常见问题

任务管理

创建与编辑

顶部快速输入条回车即建；点击任务打开编辑面板，可改标题、描述、日期、分类、优先级（高 / 低）与截止时间。

子任务

在编辑面板里拆步骤，勾选进度自动显示「已完成 / 总数」；完成父任务默认连带勾选全部子任务。

优先级与四象限

优先级分高 / 低两档，与四象限矩阵的「重要」双向打通；今日页可在列表和四象限之间一键切换。

改期与排序

在日历里拖任务到目标日期即改期；今日清单支持手动排序，顺序即刻生效。

组织：分类、标签与过滤器

分类

侧边栏管理分类，每条任务归入一个分类，分类色会贯穿时间轨与复盘图。

标签

在描述里写 #标签 即自动识别，侧边栏按标签聚合统计。

过滤器

把常用筛选条件（如「今天到期且高优先级」）存成过滤器，挂在侧边栏一点直达。

待办箱与已达成

没有日期的任务都在待办箱；已完成的按完成时间进入「已达成」，随时回看自己的积累。

日程与重复

月历视图

月 / 周 / 时间块三种视图；点击「今天」回到当天；悬停截断的事件可看完整标题。

拖拽改期

把任务拖到任意日期格子即完成改期，周 / 月视图通用。

重复任务

支持天 / 周 / 月 / 年组合，可按农历重复（如生日、节气），可设置跳过节假日；完成当前实例后自动续期下一个。

多重提醒

一个任务可以设多个提醒时间点（如提前一天 + 当天早上），互不覆盖。

番茄专注

开始与轮转

点击任务旁的番茄按钮开始专注，结束后自动进入休息并轮转；专注与休息时长都可以在设置里调整。

悬浮窗与白噪音

专注时悬浮窗缩到屏幕角落显示倒计时与任务名；内置 10 类真实录音白噪音与完成提示音，都可在设置试听更换。

放弃与补录

中途放弃就地点「放弃」并可选记原因——专注过的分钟数仍会计入账本；忘记开番茄了？右键任务可以直接补录一段专注。

24 小时时间轴

今日页左侧的时间轨记录每一段专注与休息（休息为橙色），支持点击回看与编辑关联任务。

数据复盘

切换周期

本周 / 上周 / 本月 / 上月 / 近 7 天 / 近 30 天一键切换，也支持自定义日期区间（最长 366 天）。

叙事周报

每次复盘先给你一段基于个人基线的总结：完成多少、专注多久、比平时更投入还是松懈——先读故事，再看数字。

热力图与成就

GitHub 风格活跃热力图记录每一次完成；里程碑与连续坚持会点亮成就徽章。

分享卡片

一键把本周成绩生成分享长图，可以发到社交媒体留存。

桌面体验

全局快捷键

任何界面用快捷键唤起迷你输入条，想到什么一秒记下；键位可在设置中查看与修改。

桌面小组件

半透明日历、待办卡可以钉在桌面上，回到桌面就能看到今天的安排，无需打开主窗口。

深色模式与双语

跟随系统或手动切换深浅色；界面语言中英一键切换，数据与设置互不影响。
